# 编写指南

MetaKnow 支持两种内容格式：

- **Markdown（`.md`）** — 日常写作首选，语法简洁
- **HTML（`.html`）** — 需要复杂结构或自定义样式时使用

两者可以混用，MetaKnow 会根据文件扩展名自动判断用哪种渲染方式。

## 一、Markdown 基础语法

### 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

一级标题用于页面最顶部，二级及以下用于章节划分。

### 段落与换行

```markdown
这是一个段落。

空一行可以开始新段落。
```

### 列表

无序列表：

```markdown
- 第一项
- 第二项
- 第三项
```

有序列表：

```markdown
1. 第一步
2. 第二步
3. 第三步
```

强调

```markdown
**粗体**
*斜体*
`行内代码`
```

## 二、代码块

使用三个反引号包裹代码，并指定语言：

````markdown
```javascript
const greeting = 'Hello, MetaKnow';
console.log(greeting);
````

支持的语言包括：javascript、typescript、python、bash、yaml、json、html、css、markdown、text 等。

如果不需要语法高亮，可以留空或写 text：

```markdown
```text
这是一个纯文本块
```

## 三、表格

```markdown
| 字段 | 类型 | 说明 |
|------|------|------|
| title | string | 页面标题 |
| description | string | 页面摘要 |
| category | string | 所属分类 |
```

渲染效果：

| 字段 | 类型 | 说明 |
|------|------|------|
| title | string | 页面标题 |
| description | string | 页面摘要 |
| category | string | 所属分类 |

## 四、引用

```markdown
> 这是一段引用。
> 
> 可以跨多行。
```

渲染效果：

> 这是一段引用。
> 
> 可以跨多行。

## 五、链接与图片

链接：

```markdown
[显示文字](https://example.com)
```

内部链接（跳转到其他 Wiki 页面）：

```markdown
[快速开始](#/pages/quickstart.md)
```

**或**

```markdown
[[快速开始]]
```

图片：

```markdown
![这是图片](../assets/images/example.png)
```

路径相对于当前 .md 文件的位置。推荐把图片统一放在 assets/images/ 下。

## 六、YAML front matter

每个 Markdown 文件顶部可以用 --- 包裹一段元信息：

```markdown
---
title: 页面标题
description: 一句话摘要，会用在搜索结果里
tags: [标签1, 标签2]
---

正文从这行开始。
```

MetaKnow 会解析 title 用作页面标题，description 用作搜索摘要。

## 七、HTML 页面

如果你需要更自由的结构，可以直接写 .html 文件。MetaKnow 会把内容原样插入页面：

```html
<h1>自定义标题</h1>
<p>用 HTML 写的段落。</p>
<div class="custom-block">
    自定义内容
</div>
```

**注意**：HTML 文件不会经过 Markdown 解析，所以需要用完整的 HTML 标签书写。

## 八、Giscus 评论区

你不需要做任何事。

MetaKnow 会在每个页面底部自动挂载 Giscus 评论区：

- **第一次访问**：显示"未找到讨论"，不创建帖子
- **有人留下第一条评论**：Giscus 机器人自动为该页面创建对应的 Discussion
- **后续访问**：评论正常显示

每个页面有独立的讨论线程，互不干扰。

## 九、写作建议

- 标题不要跳级，一级 → 二级 → 三级，层级清晰
- 一段不要写太长，控制在 3~5 行为宜
- 代码块一定要指定语言，高亮后更易读
- 内部链接用 #/pages/xxx.md 格式，用户点进去会正常渲染
- 图片给一个描述性的 alt，方便阅读器理解
